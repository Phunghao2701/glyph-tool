# Product

## Register

product

## Users

A single type designer or font operator working locally on a desktop or laptop. They upload TTF or OTF source fonts, review Vietnamese glyph variants, refine outlines, validate the result, and export the finished font.

## Product Purpose

VietFont Studio helps a user produce Vietnamese-ready fonts through a real, reviewable workflow from source font to validated TTF or OTF export. Connected AI providers help analyze style and propose VER variants. The VFK rules, glyph mapping, validation, and font export are the system engine. Font files stay on the user's device.

## Brand Personality

Precise, craft-focused, and dependable. The interface should respect typography while keeping project work and next actions easy to find.

## Anti-references

- A marketing landing page in place of a working font workspace.
- Mock provider, analysis, or export states that imply work completed when it did not.
- Layouts that clip project content or hide core workflow actions at smaller widths.
- Uploading raw font files or outlines to a cloud AI provider.

## Design Principles

- Lead with current projects, review tasks, and workflow status.
- Make each AI and VFK state reflect the real provider, model, and job state.
- Keep the source font local while making generated variants reviewable and editable.
- Preserve clear hierarchy across desktop, tablet, and mobile layouts.
- Use Fraunces as the single interface typeface.

## Accessibility & Inclusion

Support keyboard navigation with visible focus, provide accessible names for compact navigation, respect reduced-motion preferences, and keep text readable at mobile widths and browser zoom.
